# Broia
Broia - Browse the Internet Again

A data drive tree-based or graph-based, both can be browsed in structural way.
The Internet is the world's data drive, and thus it should be browsable.

The Internet started with Internet directories even before the search engines,
this project wants to revive the Internet directories the new way, social 
way to make it.

We have,
  - Search engines
  - AI to summarize the web
  - Broia is another approach for people to use the Internet.
